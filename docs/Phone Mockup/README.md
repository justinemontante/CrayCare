# CrayCare Phone Mockup Maker

Open `CrayCare Phone Mockup Maker.html` in a browser. No server or installation is required.

## Add a GUI screenshot

1. Save the screenshot in the `GUI Images` folder (or anywhere convenient).
2. Open the mockup maker HTML file.
3. Click **Upload image** and select the screenshot, or drag it onto the upload area. You can also paste an image with Ctrl+V.
4. Choose **Fill screen** to crop to the phone display, or **Fit whole image** to show the entire screenshot.
5. Adjust the frame and image controls if needed, then download the transparent PNG.

## Create several mockups at once

1. Turn on **Bulk upload & ZIP export**.
2. Select or drag in multiple screenshots. The first screenshot appears in the preview.
3. Set the frame, image fit, and enhancement options once; those same settings are applied to every selected screenshot.
4. Click **Download … PNGs as ZIP** to save one ZIP containing a transparent PNG mockup for each screenshot. Each output uses its source filename, with a numbered suffix if names repeat.

Bulk processing happens locally in the browser. Switch bulk mode off to return to single-image export.

The mockup maker processes selected images locally in the browser. To make mockups later, reopen the same HTML file and select the screenshots you need.
