# CrayCare Water Quality Classification

## Train the model

Run the single training script from this folder:

```powershell
py train_wqc.py
```

The script saves the trained model and evaluation report in `model/`, and exports the same forest to the Cloud Functions model file. Each export is labeled `wqc-rf-v5`. Training does not deploy the function to Firebase.

## Data and evaluation

- `datasets/water_quality_readings_oct9_nov12_from_db.csv` contains 4,962 observed database readings through November 12, 2026.
- `datasets/water_quality_readings_oct9_nov12_labeled.csv` contains observed readings with range-derived labels. Old generated rows are ignored unless their timestamp and all four rounded sensor values match a real source reading.
- `datasets/wqc_poor_scenarios_fit_only.csv` is generated by the training script. It has standards-based Poor scenarios without timestamps, so they cannot be mistaken for pond readings or collide with later real dates. These scenarios are used for fitting only.
- The Random Forest predicts Good or Poor. The approved range check assigns Critical before the Random Forest runs; synthetic examples are not used to claim learned Critical performance.
- Validation and holdout use later observed readings only, separated chronologically with a two-hour gap. Generated scenarios are excluded.
- The output report separates observed and scenario counts and includes per-class metrics and confusion matrices.
- The observed dataset has no Critical rows, so Critical performance on real pond observations cannot be measured from this dataset. Critical remains a threshold decision until real reviewed Critical readings are available.
- Labels follow the approved sensor ranges, so the evaluation measures agreement with those range labels, not crayfish health outcomes.

The deployed classifier records `model_version` with each new result so the prediction can be traced to its model. The v5 report separates Good/Poor model agreement from the Critical threshold guard and states that labels are range-derived, not independent crayfish-health outcomes.
