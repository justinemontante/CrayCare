CRAYCARE PRODUCTION FIRMWARE — SERIAL COMMANDS
Firmware environment: esp32dev_main
Baud: 115200
Line ending: Newline

IMPORTANT
- This file lists commands implemented by src/main.cpp only.
- HC-SR04 ECHO must be reduced from 5V to 3.3V before GPIO33.
- Calibration values are stored in ESP32 NVS and survive reboot.

WIFI
  RESET_WIFI
    Erases stored Wi-Fi credentials and restarts the ESP32.

FEEDER
  FEED
    Requests one manual feed using the default 20 g estimate. Feeding is blocked
    when required water-quality sensors are unavailable or outside safe ranges.

SENSOR CALIBRATION
  phcal7
    Place the pH probe in pH 7.00 buffer, wait for a stable voltage, then run.

  phcal4
    Place the pH probe in pH 4.00 buffer, wait for a stable voltage, then run.

    Both pH points are required. After the second point, firmware computes and
    saves the two-point voltage slope/intercept.

  doread
    Shows current DO raw voltage, converted mg/L, and water temperature.

  doclear
    Calibrates the DO probe at 100% air saturation using the current temperature.
    Use a sealed humid-air calibration bottle and wait for a stable reading first.

  turbclear <volts>
    Saves the measured clear-water voltage (0 NTU reference).

  turbdirty <volts>
    Saves the measured dirty-water voltage (500 NTU field reference).

  turbair <volts>
    Saves the below-this-voltage air/no-water threshold.

HC-SR04 WATER LEVEL
  tankheight <cm>
    Saves distance from sensor face to tank bottom.

  tankdepth <cm>
    Saves maximum valid water depth.

  tankcal
    Shows sensor height, maximum depth, and latest measured air gap.

  Formula: waterDepth = sensorHeight - measuredDistance

DEBUG
  raw
    Prints pH voltage, DO voltage, turbidity voltage, HC-SR04 distance, and depth.

RELAYS — LOCAL TEST
  n1on / n1off       Water pump, GPIO26
  n2on / n2off       Primary aerator, GPIO27
  n3on / n3off       Secondary aerator, GPIO14
  relay status       Shows physical relay states and cloud control modes

NOTES
- Local relay test state can be replaced by the next Firestore control sync.
- Sensor thresholds are configured in the Flutter app and synchronized from
  tanks/{tankId}/sensors/*.
- Scheduled feeding is executed by the ESP32. Android background work sends
  reminders only and must not enqueue duplicate scheduled feed commands.
- The last cloud-synced schedules are cached in NVS and continue during a Wi-Fi
  outage. Ten-minute sensor history is buffered in LittleFS and uploaded after
  reconnect. A cold boot without network still needs an external RTC for correct
  wall-clock schedule time.
