NOTE: GPIO39 is an ADC1 input-only pin and remains usable while Wi-Fi is active.
The default analog calibration is 0.50V empty and 2.80V full. Run `feedempty`
and `feedfull` after installing the actual sensor. GPIO36 remains reserved
exclusively for the dissolved-oxygen analog input.

============================================
  VOLTAGE DIVIDER CONFIGURATION
============================================

Sensor powered at 5V — verify each before connecting:

┌──────────────┬────────────┬───────────────────────────────────┐
│ Sensor       │ Divider    │ Ratio in Code   │ Status          │
├──────────────┼────────────┼─────────────────┼─────────────────┤
│ DO (SEN0237) │ 10k + 10k  │ 0.5f            │ KEEP RESISTORS  │
│ pH (SEN0161) │ 10k + 10k  │ 0.5f            │ KEEP RESISTORS  │
│ Turbidity    │ None needed│ N/A             │ Direct connect  │
│              │ (if 3.3V)  │                 │ at 3.3V only    │
└──────────────┴────────────┴─────────────────┴─────────────────┘

⚠️  IMPORTANT: SEN0189 Turbidity at 5V outputs ~3.8-4.2V.
    If powered at 5V, add voltage divider. Direct connect only
    if powered at 3.3V.

============================================
  WATER LEVEL (HC-SR04)
============================================

Tank configuration:
  - Sensor mounted at: 65cm above tank bottom
  - Tank water depth:  23cm max
  - Water depth = 65cm − measured_distance

⚠️ HC-SR04 ECHO is normally 5V. Never connect ECHO directly to ESP32 GPIO33.
   Use a 5V→3.3V level shifter or resistor divider (for example 1kΩ from ECHO
   to GPIO33 and 2kΩ from GPIO33 to GND). TRIG may connect to GPIO32.

LCD display: "W:XXcm" (actual water depth)

============================================
  SERIAL COMMANDS
============================================

COMMAND MENU / SENSOR DISPLAY
  HELP / help / ?        Show the main command menu
  SENSOR_ON              Print readings every 2 seconds
  SENSOR_OFF             Hide periodic readings (default after boot)
  SENSOR_READ            Take and print one fresh reading
  CAL_HELP               Show calibration commands
  WIFI_HELP              Show Wi-Fi commands

RELAYS
  n1on / n1off         Water Pump ON/OFF       (GPIO 26)
  n2on / n2off         Primary Aerator ON/OFF  (GPIO 27)
  n3on / n3off         Secondary Aerator ON/OFF(GPIO 14)
  relay status         Show relay states

FEEDER
  FEED                  Request one manual feed (default 20 g estimate)

WIFI (up to 5 profiles saved in NVS)
  wifi add                 Guided SSID/password entry
  wifi set <SSID>|<PASS>   Save/update profile; SSID may contain spaces
  wifi list / wifilist     List profiles; passwords stay hidden
  wifi use <INDEX>         Switch profile and restart
  wifi delete <INDEX>      Delete one profile
  wifi scan / wifiscan     Scan nearby networks
  wifi status / wifistatus Show connection and saved profiles
  RESET_WIFI               Erase every saved profile and restart

CALIBRATION
  turbclear <V>        Turbidity 0 NTU voltage
  turbdirty <V>        Turbidity ~500 NTU voltage
  turbair <V>          Turbidity air threshold
  phcal7               Calibrate pH 7.0
  phcal4               Calibrate pH 4.0
  doclear              Calibrate DO in air
  feedempty            Save current hopper voltage as empty
  feedfull             Save current hopper voltage as full

DEBUG
  raw                   Print one raw sensor reading
