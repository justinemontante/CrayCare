BLOWER (GPIO16, active-LOW relay module)
  - Wiring: GPIO16 -> relay IN, common GND, blower on its own supply.
    Relay module must trigger on 3.3V logic. Initializes OFF at boot.
  - Warm-up: auto-ON 5 s before EVERY feed (manual, cloud, scheduled),
    stays ON through dispensing, auto-OFF at DONE — unless manually ON
    via n4on, which the feed cycle never overrides.
  - Manual: n4on / n4off (15-minute safety timeout). Future app ID
    (reserved): "blower".

FEEDER GATE — SG90 180-DEGREE SERVO ON GPIO5 (LEDC ch 0, ONLY servo)
  - 1 g-only model: 1 open/close actuation = 1 g, always. Feed grams from
    the app decide the count: 5 g = exactly 5 actuations.
  - Motion per actuation: 0 -> GATE_OPEN_ANGLE (default 90) -> hold
    GATE_HOLD_MS (default 800 ms) -> 0. Tune on bench, store permanently.
  - Calibration: GATECAL runs 10 actuations — catch, weigh, expect ~10 g.
    Adjust GATE_ANGLE / GATE_MS until 10 actuations land near 10 g.
    Test a single swing with GATE_TEST.
  - Parks at 0 on boot and after FEEDER_DONE. Never actuates at boot.
  - GPIO25 door servo retired (spare). GPIO13 retired (dead output).
  - Power from separate 5V supply with common GND + ~470 uF cap on
    the servo rail. Never power servos from the ESP 5V pin.

HOPPER LEVEL (2nd HC-SR04, feed surface)
  - TRIG GPIO17 (direct), ECHO GPIO25 via 1kΩ (ECHO->GPIO) + 2kΩ
    (GPIO->GND) divider — never direct, same rule as GPIO33.
  - No ruler needed: empty hopper -> `hopperempty`, full hopper ->
    `hopperfull`. Percent = (empty - echo) / (empty - full).
    Manual values: `hopperheight <5-200>` (empty point),
    `hopperdepth <1-empty>` (max feed depth).
  - Source: ultrasonic by default; `FEEDMODE 0` forces analog GPIO39.
    A bad echo falls back to analog automatically; both invalid blocks
    feeding exactly like before. App sees identical feed_level/grams.

SD CARD (offline storage, syncs when internet returns)
  - SPI mode: SCK 18 / MISO 19 / MOSI 23 / CS 15. Active driver:
    SD is the primary offline buffer (/craycare/history.jsonl);
    LittleFS /buf/history.jsonl is the fallback with no card, and any
    LittleFS backlog migrates to SD at boot. Flush order SD-first.
  - Module VCC to 5V (onboard regulator), signals at 3.3V, common GND.
    Format card as FAT32. Check state any time with BUFSTATUS.
  - GPIO15 (MTDO) needs HIGH at boot — SD CS idles HIGH through its
    pull-up, so this assignment is safe.

NOTE: GPIO39 is an ADC1 input-only pin and remains usable while Wi-Fi is active.
The default analog calibration is 0.50V empty and 2.80V full. Run `feedempty`
and `feedfull` after installing the actual sensor. GPIO36 remains reserved
exclusively for the dissolved-oxygen analog input.

============================================
  WATER LEVEL (HC-SR04)
============================================

Tank configuration:
  - Sensor mounted at: 65cm above tank bottom
  - Tank water depth:  23cm max
  - Water depth = 65cm − measured_distance

⚠️ HC-SR04 ECHO is normally 5V. Never connect ECHO directly to ESP32 GPIO33.
   Use a 5V→3.3V level shifter or resistor divider (for example 1kΩ from ECHO
   to GPIO33 and 2kΩ from GPIO33 to GND). TRIG may connect to GPIO32.

LCD display: live 16x2 screens (sensors / feed+blower), feed progress,
BLOCKED reasons, "Fed Xg OK" banner. Silent-disabled if no
ACK at 0x27 — if your backpack is 0x3F, change LCD_ADDR in main.cpp.

============================================
  SPARE PINS (no physical buttons fitted)
============================================

  GPIO12 and GPIO2 are spare. Feeds start from app/schedule/serial only.
  GPIO2 is a strapping pin — leave unconnected at boot.

============================================
  SERIAL COMMANDS
============================================

COMMAND MENU / SENSOR DISPLAY
  HELP / help / ?        Show the main command menu
  SENSOR_ON              Print readings every 2 seconds
  SENSOR_OFF             Hide periodic readings (default after boot)
  SENSOR_READ            Take and print one fresh reading
  CAL_HELP               Show calibration commands
  WIFI_HELP              Show Wi-Fi commands

RELAYS
  n1on / n1off         Water Pump ON/OFF       (GPIO 26)
  n2on / n2off         Primary Aerator ON/OFF  (GPIO 27)
  n3on / n3off         Secondary Aerator ON/OFF(GPIO 14)
  n4on / n4off         Blower ON/OFF           (GPIO 16)
  relay status         Show relay states

FEEDER (SG90 gate on GPIO5, 1 g per actuation)
  FEED                  Request one manual feed (1-200 whole g, default 20 g)
  GATE_TEST             One gate actuation 0 -> angle -> 0
  GATECAL               10 actuations for weighing (expect ~10 g)
  GATE_ANGLE <10-180>   Gate open angle, saved to NVS
  GATE_MS <100-5000>    Gate hold ms, saved to NVS
BLOWER
  Blower auto-runs 5 s before every feed, stays ON through dispensing,
  auto-OFF at DONE unless manually ON. Manual: n4on / n4off.

WIFI (up to 5 profiles saved in NVS)
  wifi add                 Guided SSID/password entry
  wifi set <SSID>|<PASS>   Save/update profile; SSID may contain spaces
  wifi list / wifilist     List profiles; passwords stay hidden
  wifi use <INDEX>         Switch profile and restart
  wifi delete <INDEX>      Delete one profile
  wifi scan / wifiscan     Scan nearby networks
  wifi status / wifistatus Show connection and saved profiles
  RESET_WIFI               Erase every saved profile and restart

CALIBRATION
  turbclear <V>        Turbidity 0 NTU voltage
  turbdirty <V>        Turbidity ~500 NTU voltage
  turbair <V>          Turbidity air threshold
  phcal7               Calibrate pH 7.0
  phcal4               Calibrate pH 4.0
  doclear              Calibrate DO in air
  feedempty            Save current hopper voltage as empty
  feedfull             Save current hopper voltage as full

DEBUG
  raw                   Print one raw sensor reading
